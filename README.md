# Sunsail

Full-colour Python 3 neon thermal-pennon arcade for [ElbowOS](https://x.com/ElbowOS).

Bank a gold sail through descending hoop gates.
Ride gusts, snag sun motes, dodge violet storm cores.
A / D (or arrows) bank the pennon.

## Play

```
pip install -r requirements.txt
python3 sunsail.py --play
```

## Record a 9:16 reel

```
python3 sunsail.py --record
```

Writes `/home/workdir/artifacts/SUNSAIL_ElbowOS.mp4` (1080×1920, 15s, 30fps, H.264 CRF 20, yuv420p, +faststart).
